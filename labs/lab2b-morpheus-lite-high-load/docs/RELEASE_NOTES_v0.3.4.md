# Morpheus Lite v0.3.4 — Stable Lab 2b Release

This release freezes the validated high-load laboratory baseline.

## Highlights

- End-to-end telemetry, detection, alerting, orchestration, decision, and dashboard pipeline.
- Unique Kafka consumer group and explicit partition readiness for the orchestrator.
- High-load profiles: normal, burst, sustained, and attack surge.
- Rolling throughput, utilization, backlog, queue-wait, processing-time, and E2E-latency metrics.
- Pipeline health and overload diagnostics.
- CSV export established as the central Lab 2b assessment artifact.
- Student guide, instructor guide, rubric, questions, expected-results guide, sample CSV, and sample dashboard.
- Runtime data, caches, and build artifacts excluded from version control.

## Validation

The automated suite passes 14 tests in the validated release environment.
