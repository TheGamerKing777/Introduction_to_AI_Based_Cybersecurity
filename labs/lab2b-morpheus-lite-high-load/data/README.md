# Runtime Data Directory

This directory is populated while Morpheus Lite is running.

Generated files such as `audit.jsonl` and `high_load_metrics.jsonl` are runtime artifacts and are intentionally excluded from version control. `fingerprint_profiles.json` is retained as the reference baseline used by the detector.

Students do not submit internal JSONL files for Lab 2b. The required quantitative artifact is the CSV exported from the dashboard.
