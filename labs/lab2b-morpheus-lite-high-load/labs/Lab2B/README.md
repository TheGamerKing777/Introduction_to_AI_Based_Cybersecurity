# Laboratory 2b — High-Load Cybersecurity with Morpheus Lite

Lab 2b studies how an AI-native SOC behaves when incoming telemetry approaches or exceeds pipeline capacity.

## Central laboratory artifact

The primary evidence artifact is the **CSV exported from the Lab 2b dashboard**. Students use it to calculate summary metrics, identify bottlenecks, and justify engineering conclusions.

## Workflow

1. Start Redpanda, detector, orchestrator, and dashboard.
2. Run the assigned workload profile.
3. Observe throughput, utilization, backlog, and latency.
4. Download the experiment CSV.
5. Analyze the CSV in Excel, LibreOffice Calc, or pandas.
6. Submit the CSV, one dashboard screenshot, and a 1–2 page analysis.

See `LAB2B_STUDENT_GUIDE.md` for the complete procedure.
